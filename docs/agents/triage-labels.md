# Triage labels

Local Markdown uses these values in its `Status:` field.

| Role / status | Meaning |
|---|---|
| needs-triage | Maintainer evaluation required |
| needs-info | More information required |
| ready-for-agent | Fully specified and ready for agent implementation |
| ready-for-human | Human implementation required |
| wontfix | Will not be implemented |

When a skill requests a triage label, set the corresponding status.
Readiness does not itself authorize implementation.
